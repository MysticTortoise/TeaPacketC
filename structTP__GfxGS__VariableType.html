tp_u8 TP_GfxGS_VariableType::amount

The vector size of this type.

1 maps to a singular of this type (i.e. baseType = float, amount = 1 is a float). Any number above that maps to a vector of this type (i.e. baseType=float, amount = 4 is a float4 or vec4)

Any amount above the highest supported by this module implementation (typically 4) is undefined behavior.
