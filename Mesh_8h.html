void TP_GfxGS_Mesh_SetActive ( TP_GfxGS_Mesh * )

Sets a Mesh to be the currently active Mesh.

Active Meshes send their vertex data to IN attributes in GLSL. Only one Mesh may be active at a time.

Warning
Calling TP_GfxGS_DrawMesh without any active Mesh is undefined behavior.
