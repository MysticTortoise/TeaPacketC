◆ TP_Graphics_Display_BeginRender()

void TP_Graphics_Display_BeginRender ( TP_Graphics_DisplayID id)

Sets this Display to be the current active target for rendering.

Any calls to this function must be followed by a call to TP_Graphics_Display_FinishRender.

Warning
This conflicts with TP_Graphics_Viewport_BeginRender. Only have one active target at a time.

Calling this function multiple times without calling TP_Graphics_Display_FinishRender is undefined behavior.

Parameters
idThe ID of the Display that will be targeted.

◆ TP_Graphics_Display_FinishRender()

void TP_Graphics_Display_FinishRender ( void )

Finishes rendering the current Display.

This function must be preceded with a call to TP_Graphics_Display_BeginRender.

Warning
Calling this function without a prior call to TP_Graphics_Display_BeginRender, or after another call to TP_Graphics_Display_FinishRender, is undefined behavior.
