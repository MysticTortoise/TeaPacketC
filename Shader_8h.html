void TP_GfxGS_Shader_SetActive ( TP_GfxGS_Shader * )

Sets this Shader to be the currently active Shader.

The active Shader is the one used when drawing meshes. Only one Shader may be active at a time.

Warning
Calling TP_GfxGS_DrawMesh without any active Shader is undefined behavior.
