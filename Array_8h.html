#define TP_Array ( Type)

struct TP_##Type##Array{\
Type* p;\
size_t size;\
}

The TP_Array base type represents a modifiable array with a size. This should be used instead of separating the array with a pointer and a size.

Any public TP_Array types should be allocated with TP_MemAlloc and freed with TP_MemFree.

The TP_ArrayView base type represents a non-modifiable view of data with a size. This should be used to send data to functions that will not modify it.
